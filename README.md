# 🎙️ Mic Mute Controller

โปรแกรมควบคุมการเปิด/ปิดไมโครโฟนด้วยปุ่มคีย์ลัดสำหรับ Windows ขนาดเล็ก กินแรมน้อย พร้อมหน้าต่างลอยแจ้งเตือน (Floating OSD) และไอคอนใน System Tray

## ✨ ฟีเจอร์หลัก
- **Global Hotkey:** กดปุ่มคีย์ลัดเพื่อเปิด/ปิดไมค์ได้แม้ขณะเล่นเกม Fullscreen
- **Auto-Detect Microphone:** อัปเดตรายชื่อไมโครโฟนอัตโนมัติเมื่อเสียบหรือถอดสาย
- **Floating OSD Overlay:** แถบแจ้งเตือนลอยด้านล่างหน้าจอแบบทะลุเมาส์ (Click-through)
- **System Tray Integration:** คลิกซ้ายที่ไอคอนมุมขวาล่างเพื่อเปิด/ปิดไมค์ได้ทันที
- **Multi-Language:** รองรับภาษาไทยและอังกฤษ (แก้ไขหรือเพิ่มภาษาได้เองผ่านไฟล์ languages.json)
- **Run on Startup:** ตั้งค่าให้เปิดอัตโนมัติพร้อม Windows ได้
